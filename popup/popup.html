⚡ APISmoke

Autonomous API regression & smoke test suite generator.

How to use:
  1. Open any website or web application.
  2. Press F12 (or Inspect) to open Chrome DevTools.
  3. Click on the APISmoke panel tab.
  4. Hit Record and interact with your app!

Open the APISmoke tab in DevTools and enter your Kimi API key (sk-...) there. The key is used for this session only and is not saved.
